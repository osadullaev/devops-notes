## 📌 Шаг 1 — Выбор домена

### Что такое домен?
Домен — это адрес твоего сайта в интернете. Как адрес квартиры, только в интернете.
```
osadullaev.dev  =  твой адрес
.dev            =  зона (как район города)
osadullaev      =  твоё имя в этой зоне
```

### Почему .dev а не .com или .xyz?
| Зона | Для кого | Цена/год |
|------|----------|----------|
| .dev | Tech специалисты, разработчики | $12 |
| .com | Бизнес, универсально | $10 |
| .xyz | Дёшево, но ассоциируется со спамом | $1→$12 |

**Выбрали `.dev`** — потому что ты DevOps инженер, это отражает профессию и вызывает доверие в tech сообществе.

### Где купили?
**Cloudflare Registrar** — `dash.cloudflare.com` → Domains → Registrations

**Почему Cloudflare:**
- Цена без наценок (at-cost pricing) — самые честные цены
- DNS уже там же — удобно настраивать
- Надёжный провайдер, используется крупными компаниями
- WHOIS privacy бесплатно (твои данные скрыты от публичного реестра)

**Стоимость:** $12.20/год, продление $12.20/год (без сюрпризов)
**Действует до:** 14 июня 2027

## 📌 Шаг 2 — Что такое DNS?

DNS (Domain Name System) — это телефонная книга интернета.

```
Ты вводишь:     osadullaev.dev
DNS говорит:    этот домен → иди на сервер Vercel
Браузер:        открывает сайт с сервера Vercel
```

### Типы DNS записей которые добавили:
| Тип | Что делает |
|-----|-----------|
| TXT | Верификация — доказывает что домен твой |
| CNAME | Направляет трафик на серверы Vercel |

### Зачем два домена?
- `osadullaev.dev` — без www
- `www.osadullaev.dev` — с www

Люди вводят по-разному, оба должны работать и вести на один сайт. `osadullaev.dev` перенаправляет (308 redirect) на `www.osadullaev.dev`.

## 📌 Шаг 3 — Подключение домена к Vercel

### Что такое Vercel?
Vercel — платформа для хостинга сайтов. Твой сайт живёт на их серверах.

```
Твой код (GitHub) → Vercel собирает → раздаёт по всему миру через CDN
```

**CDN (Content Delivery Network)** — сеть серверов по всему миру. Пользователь из Европы получает сайт с европейского сервера, из Азии — с азиатского. Быстро везде.

### Как подключили:
1. Vercel → проект `personal-site` → Settings → Domains
   - Прямая ссылка: `vercel.com/[team]/personal-site/settings/domains`
2. Домены `osadullaev.dev` и `www.osadullaev.dev` уже были добавлены (Vercel сделал сам при деплое)
3. Нажали "Learn more" → "Auto configure"
4. Vercel сам добавил DNS записи в Cloudflare
5. Нажали "Authorize" — дали разрешение на одноразовое изменение DNS

### Что такое SSL сертификат?
SSL — это HTTPS, замочек в браузере 🔒

```
http://  — незащищённое соединение (данные передаются открыто)
https:// — зашифрованное соединение (данные защищены)
```

Vercel генерирует SSL сертификат автоматически и бесплатно через Let's Encrypt. Занимает 1-2 минуты.

## 📌 Шаг 4 — Как работает автодеплой

```
Ты меняешь файл в VS Code
      ↓
git add . && git commit && git push
      ↓
GitHub получает новый код
      ↓
Vercel видит изменение (webhook)
      ↓
Vercel собирает сайт (~30 секунд)
      ↓
osadullaev.dev обновляется автоматически
```

Это и есть CI/CD для личного сайта — как на работе, только проще.

## 📌 Шаг 5 — Исправление бага

**Проблема:** После флага 🇺🇿 отображался текст "uz"
**Причина:** Эмодзи флага состоит из двух букв кода страны (U+Z), некоторые системы показывают их как текст
**Решение:** Убрали "uz" из HTML, оставили только эмодзи флага

```html
<!-- было -->
<p class="role">DevOps Engineer · Tashkent, Uzbekistan 🇺🇿 uz</p>

<!-- стало -->
<p class="role">DevOps Engineer · Tashkent, Uzbekistan 🇺🇿</p>
```
